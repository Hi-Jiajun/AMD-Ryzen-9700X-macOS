## 5. 可复制删除命令模板（仅供展示·严禁本回合执行）

> **安全声明**：
> 1. 本文档为只读规划报告，**绝对禁止**在本任务中直接执行以下命令；
> 2. **严禁使用 `rm -rf`**，以免误伤 `EFI/` 引导目录及其子项；
> 3. 推荐优先采用 **"移动归档到本地卷（`mv`）"** 替代原地硬删除，实现 100% 可逆。

### 5.1 步骤一：Dry-Run 预演对账模板（无破坏性）

在挂载 ESP（假设挂载点为 `/Volumes/EFI`）后，先仅打印匹配的文件名与数量，不执行任何写操作：

```bash
# 【演练命令·只读预演】
TARGET_DIR="/Volumes/EFI"
BACKUP_ARCHIVE="$HOME/Documents/opencore-logs-archive-$(date +%Y%m%d)"

# 1. 检查 ESP 是否正确挂载，且存在 opencore 日志
if [ ! -d "$TARGET_DIR" ]; then
    echo "[ERROR] 挂载点 $TARGET_DIR 不存在，终止！"
    exit 1
fi

# 2. 列出将要匹配清理的 10-12 到 10-19 历史日志（共 319 份）
echo "=== 待清理的 10-12 ~ 10-19 历史日志清单（预演） ==="
find "$TARGET_DIR" -maxdepth 1 -name "opencore-2026-10-1[2-9]*.txt" -type f | wc -l
```

### 5.2 步骤二：卷外安全归档模板（推荐，可逆安全）

将待清理日志批量移动到系统本地的数据归档目录，既清空 ESP，又完整保留日志备查：

```bash
# 【操作模板·安全归档移出 ESP】
TARGET_DIR="/Volumes/EFI"
BACKUP_ARCHIVE="$HOME/Documents/opencore-logs-archive-20261022"

mkdir -p "$BACKUP_ARCHIVE"

# 1. 安全移动 10-12 至 10-19 全部历史日志（319 个）
for logfile in "$TARGET_DIR"/opencore-2026-10-1[2-9]-*.txt; do
    if [ -f "$logfile" ]; then
        mv "$logfile" "$BACKUP_ARCHIVE/"
    fi
done

# 2. 对 10-20 基线日：保留首尾两份，移动中间 4 份到归档目录
# 需保留首份：opencore-2026-10-20-034348.txt
# 需保留末份：opencore-2026-10-20-235521.txt
for midfile in \
    "$TARGET_DIR/opencore-2026-10-20-034624.txt" \
    "$TARGET_DIR/opencore-2026-10-20-100926.txt" \
    "$TARGET_DIR/opencore-2026-10-20-195500.txt" \
    "$TARGET_DIR/opencore-2026-10-20-223547.txt"; do
    if [ -f "$midfile" ]; then
        mv "$midfile" "$BACKUP_ARCHIVE/"
    fi
done

echo "[INFO] 归档完成，已从 ESP 移出 323 个文件至 $BACKUP_ARCHIVE"
```

### 5.3 步骤三：受控单步清理模板（无 `rm -rf`）

若已完成全量卷外备份，需直接在 ESP 内部彻底释放 FAT32 空间，必须采用精准限定路径与文件名的循环删除方式，**绝不使用 `rm -rf`**：

```bash
# 【操作模板·受控清理（无 rm -rf）】
TARGET_DIR="/Volumes/EFI"

# 必须确认工作目录为目标目录，且绝非系统根或主目录
cd "$TARGET_DIR" || exit 1

# 仅对精确匹配 opencore-2026-10-1*.txt 的普通文件执行单文件 unlink
for f in opencore-2026-10-1[2-9]-*.txt; do
    if [ -f "$f" ]; then
        unlink "$f"
    fi
done

# 清理 10-20 中间 4 份非基线日志
for f in opencore-2026-10-20-034624.txt opencore-2026-10-20-100926.txt opencore-2026-10-20-195500.txt opencore-2026-10-20-223547.txt; do
    if [ -f "$f" ]; then
        unlink "$f"
    fi
done

# 刷新文件系统缓冲并验证
sync
df -h "$TARGET_DIR"
```
