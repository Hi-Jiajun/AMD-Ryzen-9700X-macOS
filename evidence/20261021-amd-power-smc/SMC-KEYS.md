# VirtualSMC 键枚举与传感器分类

采样时间：2026-10-21 09:43–09:45 CST  
实例：`AppleSMC` 1 个，驱动 `com.apple.driver.AppleSMC 3.1.9`，
提供者 `as.vit9696.VirtualSMC 1.3.9`

## 1. 方法与边界

工具通过 IOKit 打开 `AppleSMC`，调用：

- `KERNEL_INDEX_SMC=2`
- `SMC_CMD_READ_INDEX=8`
- `SMC_CMD_READ_KEYINFO=9`
- `SMC_CMD_READ_BYTES=5`

没有 SMC 写命令。总键数取 `#KEY` 的值，而不是
`READ_KEYINFO` 返回的 `dataSize`。

本次结果：

```text
SMC total keys (#KEY): 65
```

分类口径：

- “真实传感器”：值来自硬件实时测量，并应随温度、转速、电压、功耗或负载变化。
- “平台键”：身份、CRC、时钟、协议、控制状态、能力位或固定占位值。
- 未展开含义的 `MS*`/`LD*` 等键只标为平台键；没有证据时不冒充传感器。

## 2. 结论

| 类别 | 键数/读数 | 结论 |
| --- | --- | --- |
| CPU 温度 `T*/TC*/TG*` | 0 | 不存在 |
| 风扇转速 `F0Ac` 等 | 0 | 不存在 |
| 风扇数量 `FNum` | 1 个，值 `0` | 只是平台声明“0 风扇”，不是转速 |
| `FAC0` | 1 个，值 `0` | 不是可用的风扇测量值 |
| 电压 `V*` | 0 | 不存在 |
| CPU 总功耗 `PCPR/PSTR` | 0 | 不存在 |
| SMC 电压/传感器导出 | 0 | 不存在 |
| 实时 CPU 频率 | 0 | 不存在；`CLKT` 等不能当 CPU 频率 |

**当前真实传感器数量：0。**

## 4. 具体缺失项

用键名直接核对：

```text
Tctl=0
Tdie=0
Tccd1=0
Fan=0
CPUFAN=0
F0Ac=0
FNum=1
PSTR=0
PCPR=0
```

`FNum=1` 表示这个键存在，值为 `0`；风扇转速键仍然全部不存在。

## 5. 不把以下对象误认成传感器

- `CLKT/CLKH/CLWK`：SMC 时钟/平台结构，不等于 CPU 当前频率。
- `FNum`：风扇数量声明，不是 RPM。
- `FAC0`：值为 0 的风扇相关平台状态，不是 RPM。
- `MSSD/MSSP`：本次读到 `0x05`，但没有证据表明它们代表硬件温度/电压。
- `EPCI`：`0x0810f000` 更像平台地址/结构值，不是功耗读数。
- `RMAC/RMSN/RSSN/RPlt`：身份/序列号类值，不是传感器。
